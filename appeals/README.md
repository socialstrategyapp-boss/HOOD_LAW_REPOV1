# Appeals

This folder is the appellate workspace for criminal matters.
It is intended for structured review of conviction appeals, sentence appeals, interlocutory issues, and NSW Court of Criminal Appeal drafting.

## Contents

- `templates/` for reusable appellate drafting precedents

## Recommended use

Create one matter-specific file per appeal and keep:

- procedural posture
- orders sought
- proposed grounds
- standard of review issues
- authority list
- record and transcript references

## Drafting standard

- separate factual history from appealable error
- identify the exact ruling, direction, finding, or exercise of discretion under challenge
- record every citation and transcript reference from verified source material only
