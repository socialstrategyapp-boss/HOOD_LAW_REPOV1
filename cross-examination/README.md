# Cross-Examination

This folder is the cross-examination workspace for witness planning and hearing execution.

## Recommended use

Maintain matter-specific notes for:

- witness objectives
- admissions sought
- topic sequencing
- credibility issues
- prior inconsistent statements
- exhibit deployment plan

## Suggested internal file types

- witness plans
- topic outlines
- impeachment notes
- hearing day running sheets

## Drafting standard

- keep propositions short, leading, and fact-based
- tie each proposition to a source in the brief, transcript, or exhibit set
- separate proof objectives from advocacy language
