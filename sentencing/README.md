# Sentencing

This folder is the primary sentencing workspace for preparation of submissions, issue framing, and collation of subjective and objective material.

## Contents

- `templates/` for sentencing drafting precedents

## Recommended use

Maintain a matter-specific working file that captures:

- offence and agreed facts summary
- maximum penalty and applicable sentencing regime
- objective seriousness issues
- subjective case material
- comparable authority research
- proposed structure for oral and written submissions

## Drafting standard

- distinguish objective gravity from subjective mitigation
- identify the exact evidentiary foundation for each submission
- verify every statutory and case reference before use
