# Judicial Profiles

This folder is the judicial analysis workspace for chamber-facing notes about judicial approach, risk points, and matter preparation.

## Contents

- `templates/` for consistent judicial analysis files

## Recommended use

Keep profiles focused on:

- procedural preferences observed in open court
- recurring evidentiary or sentencing concerns
- reasons structure and analytical tendencies
- case management style

## Drafting standard

- use only verified observations from published reasons, transcript, or direct case experience
- distinguish observation from inference
- avoid personal or speculative commentary
