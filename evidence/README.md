# Evidence

This folder is the evidence workflow space for admissibility review, objection preparation, and forensic issue tracking.

## Contents

- `templates/` for evidentiary analysis and objection drafting

## Recommended use

Use this folder to maintain:

- objection matrices
- voir dire preparation notes
- exhibit issues
- witness-specific evidentiary risks
- admissibility research notes

## Drafting standard

- identify the precise evidence under challenge
- separate relevance, admissibility, and discretionary exclusion issues
- note whether the objection is pre-trial, during evidence, or on voir dire
