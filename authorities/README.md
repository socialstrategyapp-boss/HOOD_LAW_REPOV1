# Authorities

This folder is the research and authority management workspace for criminal chambers matters.

## Recommended use

Use this folder to organise verified material such as:

- case notes
- statute extracts
- principle summaries
- issue-specific research memoranda
- running authority lists for hearings and written submissions

## Authority handling standard

- do not add an authority unless it has been checked from a reliable source
- record the proposition for which the authority is used
- distinguish binding, persuasive, and background material
- note negative treatment or factual distinctions where relevant
