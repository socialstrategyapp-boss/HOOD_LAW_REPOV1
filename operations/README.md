# Operations

This folder is the internal operations workspace for chambers systems, matter onboarding, and document control.

## Contents

- `templates/` for reusable internal workflow documents

## Recommended use

Use this folder for:

- file opening and intake
- matter extraction
- task allocation
- hearing preparation checklists
- handover notes

## Drafting standard

- keep operational records clear enough for team handover
- record source locations for extracted material
- separate verified source content from internal action items
